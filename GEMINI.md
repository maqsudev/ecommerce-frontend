# Autonomous Agent Configuration & Permissions

## Command Execution Permissions
- All project-related shell commands, package managers, development servers, test suites, and build scripts are fully authorized for automatic execution.
- Maintain seamless end-to-end execution of frontend workflows without waiting for manual command prompts.

## Project Scope
- Ecommerce Frontend built with Next.js 16 (App Router), TypeScript, Tailwind CSS, TanStack Query, and Zustand.
- Conforms strictly to `postman_collection.json`.
- Seamless fallback mock engine when backend is not running so all pages, catalog filters, cart items, checkout, payments, and admin dashboards can be tested immediately in real-time.
